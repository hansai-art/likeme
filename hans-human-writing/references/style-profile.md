# 作者聲音：林思翰

這裡記錄林思翰明確提出的寫作偏好與改稿回饋。現有樣本以短句、貼文與局部改稿為主，不能宣稱已經從完整文章語料學會本人所有文風，遇到新題材以作者當次樣本為準。

## 採用順序

1. 當次指定的用途、範圍、格式與語氣。
2. 作者明確標成「我喜歡這樣寫」的樣本，或品牌範本。
3. 下面已確認的偏好。
4. 本技能的預設寫法與外部編輯方法。

本人寫好的文字、待改 AI 原稿、外部方法與編輯示範要分開看。使用者批評一段文字，只能證明那段有問題，不能把裡面的人物、情緒或句型當成本人喜好。

## 已確認的偏好

### 語氣與稱呼

| 偏好 | 怎麼做 | 什麼時候例外 |
| --- | --- | --- |
| 平輩口吻 | 用「你」，不用「您」與敬稱，像跟朋友說話。 | 品牌或客戶指定正式稱謂。 |
| 先給有內容的重點 | 先下判斷，再交代依據與做法。 | 故事、品牌與指定格式依用途安排開頭。 |
| 具體、日常 | 用人物、動作、數字、場景與前後差異說明。課程與宣傳文案用學員日常會遇到的工作場景。 | 原稿已有的抽象主張仍有意義時保留，素材沒有就不補造。 |
| 少用內部抽象詞 | 對外文案不寫「判斷標準、驗收、工作系統」這類內部語言，改寫成讀者看得懂的動作。 | 寫給團隊內部的文件可以用。 |
| 保留現場細節 | 回顧與案例文章要留看到了什麼、AI 做了哪一步、怎麼抓到錯，不只剩抽象總結。 | 指定摘要長度時，優先留最具體的那一個細節。 |
| 不要空泛稱讚 | 不寫「非常棒的問題」「令人驚豔」這類 AI 式讚美。 | 作者確實要肯定某人，而且說得出肯定什麼。 |

### 標點與句子

| 偏好 | 怎麼做 |
| --- | --- |
| 意思群組 | 句號只放在一個意思真正說完的地方，同一個意思用逗號往前推，例如「雨停了，我還坐在騎樓下，不想回去。」 |
| 不用分號 | 「；」一律改逗號或句號。 |
| 不用破折號 | 不出現「——」。 |
| 少用頓號 | 兩三項用「和」「跟」或逗號，一句不堆一串「、」。 |
| 不切碎短句 | 不把同一個意思切成 AI 式的單行碎句，有作用的短句可以留。 |
| 轉折自然 | 不用「但我先講」這類預告式轉折。 |
| 台灣用語 | 影片、軟體、硬體、程式、網路，不用對岸詞。 |

### 回答與回覆的長度

- 問題越短，回答越短。學生或客人一句話的問題，直接回答，不延伸成完整導覽，也不疊防禦性聲明。
- 只有省略會造成明顯誤判時，才補最短的一句限制。
- 客服與學員回覆用純文字、自然段，直接回答。非課程內容不導購。

### 幽默

- 偏好一口氣看懂、只轉一層、有明確反轉的笑點。
- 不喜歡詩情畫意、多層轉譯、抽象名詞堆疊、需要事後解釋或要讀者自己補前提的笑點。
- 不希望 AI 自動套用外部網路梗。原稿有、作者樣本有才保留。

### 刪與留

| 偏好 | 怎麼做 | 應保留的情況 |
| --- | --- | --- |
| 刪無效旁白 | 沒新增內容的預告、重複道理、寫作旁白直接刪。 | 作者的回想、批評、幽默或轉折影響意思時保留。 |
| 保留口語與例子 | 「想傳狗，就傳狗」「奇怪的東西」這種有畫面的口語原樣保留。 | 已經自然的句子不為了工整換同義詞。 |
| 直接處理限制 | 寫報名、付款、適用條件或目前進度，不用「但不代表」包一層。 | 有用的提醒、否定、未知結果與責任完整保留。 |
| 有功能的重複 | 貼文裡刻意重複的句子是節奏，保留。 | 同一個道理換句話講第二次才刪。 |

## 公開 FB 貼文的結構

只在使用者要發 FB 或社群貼文時套用。若環境中有專門的 FB 排版技能，排版交給它，這裡只管內容取捨。

- 開頭直接丟最有反差的一句，可以用讀者原話開場，不鋪陳、不自我介紹。
- 按事件順序推進，資料後面接作者的主觀判斷。
- 用具體場景與踩坑，保留誠實邊界，不硬說成功。
- 結尾分兩句。先輕收一句，把話收小、留一點保留，例如「畢竟只試了一場，我自己也還在觀察」這種句型，不是把心得再講一次，接著再加一句好回應的互動邀請。輕收句的內容要來自素材，素材沒有可收的保留，就用素材裡最小的那個事實收尾。
- 區塊用「█ 標題」分隔，標題裡的數量要跟實際內容對齊。
- 不用編號列表、粗體、Markdown 標題與表格，FB 不支援。
- 保留具體數據、案例、人名與金額，刪抽象觀點與延伸推論，措辭偏中性，少用帶情緒的判斷語。
- 新題材先給兩個版本讓作者選，選定後再校準。兩個版本只用「版本一」「版本二」標開，前後不加「先給兩版」「你挑一個」這類說明，貼文裡也不補素材沒有的句子。兩個版本差在開場切角，其他結構一樣要完整，每一版都要反差開場，每一版結尾都要輕收句加互動邀請。

## 用樣本校準

讀樣本的用字、句長、標點、正式程度、情緒強度與主張方式。只移用寫法，不移用樣本中的客戶、成果、職稱、情緒或經歷。

例：品牌樣本用「今晚，留一點時間給自己」與一個 ✨，就保留那種節奏與 emoji 數量，不改成技術公告，也不強行在每段加「我會建議」。

## 原文自然時

> 想傳狗，就傳狗。
> 想傳旅遊，就傳旅遊。
> 今天吃了什麼奇怪的東西，也可以拍。
> 總之，只要是影片都行。

這四句有畫面、有節奏。保留詞語與分行，只有當次指定合併或整理時才按範圍調整。不要換成「寵物、旅遊或日常生活」，也不要每句補一段作者感想。

## 收到新的回饋

把新回饋記成「要求、問題、適用範圍、應保留的反例」，再加進對應的試跑。單次主題的寫法不自動變成所有文章的規則。

| 回饋 | 先做什麼 |
| --- | --- |
| 刪太多 | 回到原文，補回被誤刪的資訊、推理、故事與作者判斷。 |
| 太 AI | 定位是重複主張、時代帽子、假感想、節奏模板，還是限制被補句蓋住，修具體位置。 |
| 不像我 | 比對樣本，找出差在用字、句長、標點、開場還是立場強度。 |
| 只改這句 | 以最近的完整稿為底，只動指定句，其他已接受的修改保留。 |
