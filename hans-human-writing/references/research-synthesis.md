## 研究與規則的關係

| 要解決的問題 | 使用的判斷 | 應保留反例 |
| --- | --- | --- |
| 無效句換成另一句無效句 | 沒增加內容就直接刪，讓前後內容自然相接。 | 有承諾、轉折或讀者行動的句子保留。 |
| 口語被分類摘要取代 | 判斷例子是否有畫面與用途。 | 狗、零食、下班路上等具體例子保留。 |
| 節奏像模板 | 按句意安排句長、停頓與段落。 | 自然排比、有意重複與故事停頓保留。 |
| 語氣修順但責任漂移 | 核對誰做什麼、何時回覆與完成狀態。 | 「明天回覆」不變成「明天寄出」。 |
| 刪免責時也刪條件 | 將可行動的限制寫成具體規則。 | 付款、候補、不含運費與檔案限制完整保留。 |
| 像本人變成補造故事 | 分開作者樣本、待改材料、假設與示範。 | 真實作者判斷與已提供經歷保留。 |
| 模糊研究被寫成事實 | 來源歸屬與論斷一起保護。 | 一般潤稿不擅自刪除有效論斷，缺出處時正文外提示。 |
| 只靠原則抓不到句型痕跡 | v4 新增痕跡目錄，用「這句在做什麼」分類，診斷用不比對。 | 「不是 A 而是 B」有真區分、三項都有內容時保留。 |
| 去 AI 味後換成另一種 AI 腔 | v4 新增假人味一組，金句、反應鏡頭、轉變故事、網路梗作者沒寫就不加。 | 作者提供而且推動事件的停頓與轉變保留。 |
| 繁體字但對岸用語 | v4 新增台灣用語與標點，依語境判斷。 | 物理「質量」、幾何「水平」、引號原話與平台專名保留。 |
| 技能自己違反作者標點 | v4 把技能文件裡的分號與破折號全部移除。 | 英文、URL、程式碼的原格式保留。 |

## 版本與驗證紀律

新規則要有實際失敗案例與可能誤傷的反例。執行者收到技能與任務，不收到預期答案。保存題目、讀取的技能檔案雜湊、完整原始輸出與核對結果。

歷史評測是歷史紀錄，手動寫的預期輸出不計入通過。完整試跑與局部試跑分開報告，品質判斷不能用 README 長度、提交次數或 AI 偵測分數代替。

作者覺得不像本人時，先用具體改稿回饋定位問題，再改相應範圍，避免從過度改寫滑向完全不改。
