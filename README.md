# 像我本人 LikeMe

台灣繁體中文寫作與改稿 Skill。根據你提供的素材、立場和用途撰寫新稿，或修改現有文章與文案。

## 可以做什麼

- **撰寫新稿：** 社群文章、課程公告、案例分析、教學、客服回覆、商務通知與產品文案。
- **修改現有內容：** 把模糊的描述寫清楚、整理段落、刪掉真正重複的內容，讓讀者容易理解重點。
- **保留重要資訊：** 作者的語氣與立場、事實、數字、日期、網址、條件、承諾和具體例子。
- **保留自然原文：** 句子已經自然清楚時就不硬改；只要求整理標點或分段時，只調整標點或分段。

## 改寫前後範例

### 把抽象描述改成具體行動

**改寫前**

> 這時候他們做了一個後來價值 16.5 億美元的決定。

**改寫後**

> 團隊取消了約會影片的限制，開放其他內容上傳。

把「做了一個決定」改成實際行動，讀者就知道團隊改了什麼。

### 原文自然，就保留原文

**改寫前**

> 想傳狗，就傳狗。  
> 想傳旅遊，就傳旅遊。  
> 今天吃了什麼奇怪的東西，也可以拍。  
> 總之，只要是影片都行。

**改寫後**

> 想傳狗，就傳狗。  
> 想傳旅遊，就傳旅遊。  
> 今天吃了什麼奇怪的東西，也可以拍。  
> 總之，只要是影片都行。

### 根據素材寫出明確的客服回覆

**素材：** 包裹漏了轉接頭，正在確認補件庫存，明天下午 3 點前回覆庫存結果，寄出時間尚未確定。

**改寫前**

> 包裹缺少轉接頭，我們會盡快處理，請放心。

**改寫後**

> 包裹漏了轉接頭，抱歉。我們正在確認補件庫存，明天下午 3 點前回覆結果，確認後再告訴你寄出時間。
