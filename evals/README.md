## 重跑方式

1. 固定要使用的技能版本，記錄技能資料夾內檔案的 SHA-256。
2. 在新執行緒給執行者 SKILL.md 與原始任務，不給驗收條件、預期答案或上一輪輸出。一次多題時記錄分組，不能宣稱每題各自獨立。
3. M01 先取得第一輪完整稿，再給第二輪的局部修改要求，兩輪都保存。
4. 把完整輸出原樣存入紀錄，再依驗收條件標記 pass、fail 或 blocked，寫出具體原因。人工修改的預期文字不算實際輸出。
5. 改動行為規則後重跑受影響題目，新增可能誤傷的反例，再完成一次全題庫核對。文件或連結更正只做對應檢查。

長篇題 L01 是測試用專案素材，品牌題 S02 是模擬品牌範本。通過數衡量這批任務的資訊、範圍與閱讀要求，不等於已用完整作者文章語料驗證文風。
