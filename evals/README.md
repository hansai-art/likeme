# 寫作驗證

這個資料夾保存可重跑的題目、原始輸出與人工判讀。

## 基線

2.2.0 的歷史題目包含改稿、保留原文與新寫文章，涵蓋課程公告、客服、產品觀點、技術說明、URL、數字、引語、自然敘事與素材中的無關指令。這些結果可作為基線，但不能把後來手動調整的預期輸出當成新版本的實際試跑。

## v3 驗收規則

v3 每次修改後都要從 prompts.json 重新執行，另加 v3-acceptance.md 的回歸題。每一筆輸出記錄：

- 技能版本。
- 執行日期與環境。
- 原始任務。
- 完整原始輸出。
- 通過、失敗或尚未執行。
- 具體失敗原因。

驗收看資訊與決策品質，不看固定的「AI 味分數」：

- 事實、數字、URL、責任、限制與先後順序有沒有保住。
- 作者判斷有沒有被磨成空話。
- 原文自然時有沒有被不必要地改寫。
- 真正需要改的模糊內容有沒有變具體。
- 沒有來源的成果、經歷、引語與承諾有沒有被新增。
- 同一條規則有沒有誤傷另一種用途。

沒有實際重跑前，不能把預期文字寫進 outputs.json，也不能把題目標成完成。
