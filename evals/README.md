# 寫作驗證

[原始題目](prompts.json) · [實際輸出](outputs.json) · [人工判讀](results.md)

累積 16 題：8 題改稿、7 題保留、1 題新寫。測試題目都是教學情境，網址 `example.org` 也是測試用。

## 重跑方式

1. 準備一個沒有這次測試結果的新工作階段，交給它完整技能。
2. 只提供 `prompts.json` 的任務，要求每題直接完成。
3. 存下實際輸出，再對照素材與要求核對。
4. 看事實、意思與條件是否完整，是否有虛構，語氣問題是否真正改善。
5. 保留題核對原文是否被無必要地換詞；新寫題核對假設、立場與操作方式。

不要把結果或期待答案先給執行者。每次換模型、技能版本或任務材料，就另外記錄日期、條件與輸出，未重跑的題目保留原執行版本，不能算作新版本的通過數字。

若有未完成的題目，指出漏掉哪項要求，保留原始輸出，修技能後另存新一輪結果。
