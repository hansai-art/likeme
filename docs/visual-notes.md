## 封面創作指示

以下是創作需求的整理，供重新設計使用：

```text
Use case: illustration-story
Asset type: GitHub README editorial cover, wide 16:9
Primary request: an original paper collage about editing tangled writing
into a clear manuscript.
Scene: a bright white desk, cream manuscript paper, subtle tactile texture.
Subject: tangled black ink and scattered manuscript scraps become a single
red editing line, guided by a hand holding a red pencil beside a neat page.
Style: editorial mixed-media collage, realistic paper and hand,
black ink, warm cream, restrained red and small ochre accents.
Composition: one continuous scene, roomy white space, no boxed panels.
Constraints: no readable text, no logos, no imitation browser interface,
no certification stamp, no grid background, no presentation cards.
```

參考其他專案時，學習的是配圖幫助讀者看懂編輯的用途，封面的紙張、墨線與編輯動作另行設計。

## 教學圖怎麼讀

編輯示範圖的第一組把「做了一個決定」改成團隊實際採取的行動，並避免把後來的收購金額算到這個決定上；第二組保留原本口語與例子，清楚標示原文不必改寫。完整例子見 [正反例文件](../hans-human-writing/references/editing-examples.md)。

安裝圖只畫實際檔案，不模擬產品介面，三種工具的目錄、安裝指令與確認步驟見 [圖文教學](guide.md)。
